แปลเกมนี้เป็นภาษาไทยให้ครบทุกขั้น เหมือนปุ่มในโปรแกรม: $ARGUMENTS

ทำงานที่รากโปรเจกต์ (`C:\Users\watch\game-translator`) และรายงานผู้ใช้เป็นภาษาไทยสั้นๆ ทีละขั้น

1. **เตรียมงาน:** รัน `python -m gt.cc prepare "<เกม>" [--limit N] [--locres ไฟล์]` (ส่งอาร์กิวเมนต์ที่ผู้ใช้ให้มาตามนั้น)
   - ถ้าขึ้น "ผิดพลาด": อธิบายให้ผู้ใช้แล้วหยุด — ถ้าบอกว่าแตกข้อความเองไม่ได้ (Oodle/เข้ารหัส) ให้บอกวิธีแตก `Game.locres` (ภาษา en) ด้วย FModel แล้วสั่งใหม่พร้อม `--locres <ไฟล์>`
   - บอกผู้ใช้: จำนวนที่ต้องแปล, จำนวนชุด, คำเตือน ⚠ (เช่น ต้องมีตัวข้ามลายเซ็น)
   - ถ้า "ต้องแปล 0" ข้ามไปขั้น 4

2. **แปล:** อ่านโฟลเดอร์งานที่ prepare พิมพ์ออกมา (มี `BRIEF.md` + `batchNN.json`) แล้วส่งผู้ช่วย (Agent, general-purpose) แปลขนานกัน
   - ผู้ช่วย 1 ตัวต่อ 1–2 ชุด และรันพร้อมกันไม่เกิน 8 ตัว ถ้ามีชุดมากกว่านั้นให้ทยอยส่งเป็นรอบ
   - prompt ของผู้ช่วยแต่ละตัว: "อ่าน <โฟลเดอร์งาน>\BRIEF.md ให้จบแล้วทำตามทุกข้อ แปลไฟล์ batchNN.json (ระบุเลขชุด) เขียนผลเป็น batchNN.th.part1.json, batchNN.th.part2.json, … (ใส่เลขจริง เช่น batch00.th.part1.json) ในโฟลเดอร์เดียวกัน แล้วรัน `python -m gt.cc check "<เกม>" NN` จนไม่เหลือปัญหา ตอบกลับแค่ชื่อไฟล์ที่เขียนและจำนวน id"
   - รอให้ทุกตัวเสร็จ (จะได้รับแจ้งเตือนเอง อย่าเดาผล)

3. **ตรวจและบันทึก:** รัน `python -m gt.cc apply "<เกม>"`
   - ถ้าขึ้น "ต้องแก้ 1 รอบ": ส่งผู้ช่วย 1 ตัวให้อ่าน `BRIEF.md` และ `fix.json` แล้วเขียนคำแปลที่แก้แล้วทุก id ลง `fix.th.json` (รูปแบบเดียวกับไฟล์ผลแปล) จากนั้นรัน apply อีกครั้ง — แก้แค่รอบเดียว ที่เหลือคงภาษาอังกฤษไว้

4. **ติดตั้ง:** รัน `python -m gt.cc install "<เกม>"` (สำรองไฟล์เดิมให้อัตโนมัติ — ผู้ใช้อนุมัติให้ติดตั้งเลยโดยไม่ต้องถาม) ถ้าขึ้นว่าไฟล์ถูกล็อก ให้บอกผู้ใช้ปิดเกมก่อนแล้วสั่ง install ใหม่

5. **เช็คม็อดเดิม:** ถ้าเกมนี้ต่อยอดม็อดไทยที่มีอยู่ และรู้ที่อยู่ไฟล์ม็อดต้นฉบับ (เช่น Maneater ดู `/check-mod`) ให้รัน `python -m gt.compare <ม็อดต้นฉบับ> <โฟลเดอร์เกม>` แล้วรายงานว่าคำแปลเดิมอยู่ครบไหม

6. **สรุป + บทเรียน:** สรุปให้ผู้ใช้: แปลเพิ่มกี่บรรทัด, ไม่ผ่านกี่บรรทัด, ติดตั้งที่ไหน, สำรองไว้ที่ไหน, ค่าใช้จ่าย (ไม่มีค่า API — ใช้โควตาแพ็กเกจ Claude)
   แล้วเสนอบทเรียนใหม่ 3–10 ข้อ (ภาษาไทย) จากปัญหาที่เจอรอบนี้ ให้ผู้ใช้เลือก — บันทึก**เฉพาะข้อที่ผู้ใช้เลือก** ด้วย `python -m gt.cc lesson style|lessons "<ข้อความ>" "<ชื่อเกม>"`
   ถ้าผู้ใช้สอนคำศัพท์ เช่น "Infamy = ค่าหัว" ให้บันทึกด้วย `python -m gt.cc teach "<เกม>" "<คำสอน>"`
